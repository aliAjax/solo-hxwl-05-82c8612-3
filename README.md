# 多鱼缸水质工作台（离线 PWA）

一个完全离线可用的多鱼缸水质管理工具：按缸型维护各指标安全区间，登记检测与换水记录，
系统综合**越界程度、连续恶化趋势、换水周期**生成维护待办并展示判定依据；趋势图支持时间
筛选、多缸对比与异常点定位。数据仅保存在本浏览器 localStorage，刷新全量恢复。

## 运行

```bash
npm install
npm run dev        # http://localhost:5105
# 或生产构建
npm run build && npm run preview
```

首次打开会写入一组示例数据（可在「导入导出/设置」中清空或恢复）。

## 功能

- **鱼缸管理**：新增 / 编辑 / 归档 / 彻底删除（记录进回收站），可切换查看在养与归档缸。
- **缸型阈值**：内置草缸、海缸、三湖缸、繁殖缸四套安全区间与换水周期；可新建缸型或按指标
  勾选启用区间并修改上下限（闭区间，边界值视为安全）。
- **检测记录**：pH / 氨氮 / 亚硝酸盐 / 硝酸盐 / 硬度 GH / 温度，录入数值与时间，超出当前缸型
  区间会即时警示（仍可保存，将生成待办）；物理可行域外的值直接禁止。
- **换水记录**：比例（%）+ 时间 + 备注，快捷比例按钮，自动显示距上次换水天数。
- **维护待办**：
  - 越界程度按区间宽度归一：轻微→提醒，≥15%→警告，≥50%→紧急；
  - 连续 ≥2 次同向逼近边界（余量 <15%）→趋势提醒，≥4 次升级并放大已有越界待办；
  - 超换水周期 1×→提醒、1.5×→警告、2×→紧急；无换水记录单独提醒。
  - 每条待办可展开全部**判定依据**（实际数值、区间、倍数、百分比）。
- **趋势**：7/30/90 天/全部/自定义日期筛选；多缸勾选对比（安全区间带 + 各缸折线）；
  异常点自动定位（越界、相邻突变 >40% 区间宽、偏离中位数 >3×MAD），列表给出原因。
- **撤销/重做**：所有写操作（含删除、批量导入、清空、导回）都是单步快照，可 Ctrl/⌘+Z、
  Ctrl/⌘+Y。操作后弹出的提示上有专属「撤销」按钮，即使期间又做了其它操作，点旧提示也
  **只回退那一次**（之后又被修改的记录会保留并计数，不会误删），随后仍可 Ctrl+Y 重做该次。
- **严格日期**：导入/恢复按真实日历校验，`2026-02-30`、`2023-02-29`、4 月 31 日等不存在
  的日期一律拒绝并报出**文件名 + 行 + 时间列**，绝不自动滚动到 3 月。
- **缸型容错**：缸型数据为空、段损坏或缸引用了已删除缸型时，自动回退内置缸型/运行时兜底
  缸型（14 天周期、不做阈值判定），页面正常启动不白屏，并在启动横幅说明。
- **导入导出**：
  - JSON 全量备份（缸、缸型阈值、记录、回收站；稳定键序，导出→导回→再导出字节一致，无损往返）；
  - CSV 检测/换水表格（带 BOM，Excel 友好），按鱼缸名称匹配；
  - 导入前预检，错误定位到**具体行与列**（如「第 4 行 · pH列：abc 不是数字」），
    问题行不导入、有效行照常导入，整批可撤销；提供 CSV 模板下载。
- **损坏数据隔离**：启动时逐条校验，根 JSON 损坏→隔离原文并以空数据启动；数组段损坏→跳过该
  段保留其余；单条字段错误→剔除坏字段保留记录；启动横幅列出所有问题位置并可下载隔离原文。
- **离线**：Service Worker 缓存外壳与静态资源，断网可打开、可操作；localStorage 不依赖网络。

## 测试

- `npm run typecheck` — TypeScript 严格类型检查。
- `npm run test:unit` — 20 项核心逻辑测试（阈值边界、待办等级、恶化趋势、换水周期、
  刷新恢复与损坏隔离、CSV/JSON 导入失败定位、无损往返、异常点、撤销快照模型）。
- `npm run test:e2e` — Playwright 真实浏览器 9 项端到端（需先 `npm run preview`；
  覆盖阈值边界 UI、刷新恢复、删除/导入撤销、导入失败定位、备份往返、损坏横幅、断网加载）。

## 技术栈

React 19 + Vite + TypeScript，零运行时第三方依赖，自绘 SVG 趋势图，localStorage 持久化，
手写 Service Worker（public/sw.js）实现离线。
